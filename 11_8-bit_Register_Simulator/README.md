# 8-bit Register Manipulation Simulator

A C-based simulator that models an 8-bit hardware register.

## Planned Features

- Set bit
- Clear bit
- Toggle bit
- Read bit
- Write register value
- Display register in binary

## VLSI Relevance

The project demonstrates bitwise operations, pointers, bit masking and register manipulation concepts used in low-level hardware-oriented programming.

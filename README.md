## VLSI-Oriented Project

### 8-bit Register Manipulation Simulator

A C-based project that simulates manipulation of an 8-bit register.

The project demonstrates:

- Bit setting
- Bit clearing
- Bit toggling
- Bit reading
- Bit masking
- Bit shifting
- Pointer-based register manipulation
- Binary and hexadecimal representation
